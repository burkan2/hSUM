# Support

hSUM is an alpha-stage, local-first CLI and MCP server. Public support covers
the latest GitHub alpha release on macOS arm64 and Linux x86_64 local filesystems.

- Use GitHub Issues for reproducible bugs and documentation gaps.
- Use GitHub Discussions for usage questions and design ideas, once enabled.
- Use the private vulnerability-reporting path in [SECURITY.md](SECURITY.md)
  for security concerns, never a public issue.

When reporting a problem, include `hsum --version --verbose`, the command you
ran, the stable error code/subcode, and a minimal non-sensitive reproduction.
Do not include index databases, trust files, citations to private source, or
private source contents unless explicitly requested through a secure channel.
